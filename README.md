# LINE-STAMP-SAPO

**キャラクターの魅力を活かし、Museで文字入りLINEスタンプを制作するための調査・デザイン・制作手順集。**

そらさんの「キャラ画像を渡して文字をつけてもらう制作で、自動時のバリエーションとクオリティを上げたい」という依頼をもとに整理しました。

標準の対象は、既存キャラクター画像を使う**通常の静止画クリエイターズスタンプ**です。文字組みを原画と文言に合わせて選び、候補を比較し、セット全体まで確認するための資料です。

## まずここから

短く伝える場合は、次の文をそのまま使えます。

```text

資料内の仮例と、今回の指定・実際に確認できたことを区別し、必要な資料とテンプレートを使って制作してください。
```

## 大切にすること

- **原画の魅力を活かす。** 顔・線・配色・体型・衣装などの特徴を維持して文字を組む。
- **言葉と絵を一緒に考える。** 使用場面、感情、原画の形や向きから文字の配置を選ぶ。
- **共通の雰囲気と変化を両立する。** 書体や色の方針を共有し、位置・行数・強弱・キャラとの関係を変える。
- **文字を大きく読みやすくする。** 改行、配置、字間、内部の余白を調整し、顔や意味のある手の仕草も見せる。
- **候補を見て選ぶ。** 拡大画像だけでなく、小さな一覧、明暗の背景、トーク画面で確認する。
- **次の制作に経験を残す。** 好み、採用理由、修正した点を短い制作ルールにする。

### 公式情報と提案の区別

規格は通常の静止画スタンプの[公式制作ガイドライン](https://creator.line.me/ja/guideline/sticker/)を基準にしています。最終確認日は2026年11月11日です。

資料内の候補数、レイアウト分類、制作順、サンプル文言などは、この用途に合わせた**制作上の提案**です。2022〜2023年の公式記事は基礎的な制作解説として参照し、現在の売上順位を示す資料とは区別しています。

作品ごとの最新のユーザー指示を優先し、申請時には対象のスタンプ種類の最新規格を確認してください。
