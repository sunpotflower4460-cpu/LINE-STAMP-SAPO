# 調査結果と出典 — LINEクリエイターズスタンプの自動制作

確認日：**2026年11月11日（日本時間）**  
対象：そらさんの既存キャラクター画像に文字を組み合わせる、通常の静止画クリエイターズスタンプ。  
目的：Museが原画の魅力を保ち、用途の違いと見た目の変化を持つスタンプを安定して制作するための根拠を残す。

## 1. この資料の読み方

本文では、次の3種類を区別する。

- **公式事実**：制作規定、提供機能、公式記事に実際に書かれている内容。出典番号を付ける。
- **解釈**：公式情報を今回の「既存原画への文字合成」に当てはめた考え方。
- **制作提案**：このリポジトリで採用を提案する進め方。LINEの必須条件や検証済みの販売法則ではない。

出典の公開日と確認日は別である。2022年の公式Tipsを2026年に確認しても、2026年の市場調査や最新売上データにはならない。
今回確認したのは公開情報であり、そらさんの作品別販売実績、Museの内部モデル、実行環境、現在の出力品質は調査対象に含まれていない。

制作上の具体例は [デザイン資料](02_DESIGN_PLAYBOOK.md)、工程は [制作手順](03_PRODUCTION_WORKFLOW.md)、検品は [品質確認](04_QUALITY_CHECKLIST.md) を参照する。

## 2. 通常の静止画スタンプの制作規定

### 2.1 画像の規格【公式事実】

以下は通常の「スタンプ」の公式制作ページで確認した内容。[S01]

| 項目 | 確認した規定 |
|---|---|
| スタンプ画像の個数 | 8・16・24・32・40個から選択 |
| スタンプ画像の寸法 | 最大で横370px × 縦320px |
| メイン画像 | 横240px × 縦240px、1個 |
| トークルームタブ画像 | 横96px × 縦74px、1個 |
| 各画像の容量 | 1MB以下 |
| 形式 | PNG |
| 画像の縦横寸法 | 偶数px |
| カラーモード・解像度 | RGB、72dpi以上 |
| 背景 | 透過 |
| ZIPで一括アップロードする場合 | 60MB以下 |
| スタンプの外側の余白 | トリミング後の外枠とコンテンツの間に約10px |

審査をリクエストした後は、セット内の個数を変更できない。[S01]
370 × 320pxは上限であり、全スタンプの内容をその縦横比へ変形する指定ではない。

**制作提案**：原画と文字を等比のまま配置し、外側の必要な余白と、絵・文字の間の空間を別々に扱う。高解像度で作業する場合も、最終出力サイズへ縮小した画像で検品する。

### 2.2 余白はスタンプの種類によって違う【公式事実】

| 対象 | 確認した余白の扱い | 今回への適用 |
|---|---|---|
| 通常の静止画クリエイターズスタンプ | 外枠と内容の間に約10px | 今回の基準。[S01] |
| カスタムスタンプ | 約10pxの余白を案内 | 購入者がキーワードを設定する別種。[S03] |
| メッセージスタンプ | アップロード時の余白不要。システムが追加 | 通常スタンプには転用しない。[S04] |
| ポップアップスタンプ | スタンプ画像には余白を自動追加。ポップアップ画像・同メイン画像は別扱い | 通常スタンプには転用しない。[S05] |
| LINEプロモーションスタンプ | 納品時に余分な透明領域を削除する案内 | 企業向け販促商品の案内。通常スタンプの根拠にしない。[S06] |

**解釈**：「文字を後から入れる制作方法」と、商品種別としての「メッセージスタンプ」は別である。Museで文字を合成してPNGを作るだけなら、通常スタンプとして制作できる。

**制作提案**：通常スタンプでは必要な約10pxを保ちつつ、その内側に不必要に大きな空間を残さない。髪・耳・文字の縁・装飾など、見える要素を含めた外形で余白を判断する。細い線や半透明の縁を切り落とさない。

### 2.3 画像内の文字と、商品説明の文字は別【公式事実】

タイトル40文字、クリエイター名50文字、説明文160文字、コピーライト50文字という上限は、登録する商品情報の規定である。全角は2文字として数え、コピーライトは英数字のみとされる。[S01]

この商品情報の文字数を、そのままスタンプ画像内のセリフの上限と解釈しない。今回確認した通常スタンプの制作規定には、文字の最小px数や縁取り幅の一律の数値指定は見当たらない。

**制作提案**：読みやすさは完成画像の縮小表示で判断する。指定文言を収めるために縮小を繰り返す前に、改行、文字の配置、原画との距離を見直す。

## 3. 品質とバリエーションに関する公式の知見

### 3.1 文字は「使う場面」を伝える【公式事実】

公式の文字入れ記事は、挨拶や返事などの文言が使用場面を分かりやすくすると説明する。少ない文字数、大きく読める文字、背景に埋もれないアウトラインなどを推奨している。文字なしのスタンプを一律に否定しているわけではない。[S07]

**解釈**：同じキャラクターでも、セリフと組み合わせることで「お礼」「確認」「励まし」などの役割を明確にできる。短い文言でも口調によって使える相手は変わる。

**制作提案**：文言を決める工程と、文字を配置する工程を分ける。指定文言は正確に維持する。提案を依頼された場合は、送る相手、用途、敬語か親しい口調かを整理してから選ぶ。

### 3.2 変化を付ける対象は複数ある【公式事実】

公式の制作ポイントでは、同じようなデザインが並ぶ単調さを避け、ポーズ、表情、構図、装飾、色などを工夫すると説明している。また、1つのスタンプで伝える感情を絞ることを推奨している。[S08]

**解釈**：同じフォント・同じ上部配置だけで全枚数を処理すると、文言が違っても似た印象になりやすい。一方、毎回別の書体や配色を使えば、同じキャラクターのセットとしてまとまりにくくなる。

**制作提案**：キャラクター、線、基本配色、文字の読みやすさを固定し、文字位置、行数、文字と原画の大きさの関係、強調箇所、少量の装飾を変える。表情やポーズの追加生成は、今回の制作で許可された場合に行う。

### 3.3 感情を表す部分を大きく見せる【公式事実】

公式の感情表現の記事は、顔や手足の動きなど、感情を伝える部分を大きく見せることを勧める。小さなサインを身体の比率どおりに描くと、縮小時に伝わりにくい例を示し、太く大きな文字も推奨している。[S09]

**解釈**：レイアウトでは、原画全体の面積だけでなく、顔、目、口、意味のある手の動きが見えるかを優先する必要がある。

**制作提案**：原画ごとに隠してはいけない部分を記録する。文字と装飾でそこを塞がない。原画の拡縮は等比で行い、顔や手だけを変形して大きくする処理は標準にしない。

### 3.4 淡い絵柄も、輪郭や表情を読み取れるようにする【公式事実】

公式の色合いの記事は、トーク背景との同化と、顔色に目・口が埋もれる問題を挙げている。水彩やパステルの淡い着色では、輪郭を濃く太めにする工夫を紹介している。[S10]

**解釈**：柔らかい雰囲気を保つことと、文字や表情の視認性を確保することは両立できる。全体の彩度を上げることだけが改善方法ではない。

**制作提案**：明るい背景、暗い背景、模様のある背景で確認する。まず文字の色、縁取り、配置を調整し、原画の色や線を変更する必要がある場合は案件の許可範囲に従う。

### 3.5 セット全体の構成案を先に作る【公式事実】

公式は、表現したい挨拶や感情を一覧にした構成案を先に作ることを勧める。日常の返事・挨拶を軸に、似た内容への偏りを避ける考え方が示されている。[S11][S12]

S11の「24枚中、ポジティブ12・中間8・ネガティブ4」は記事内の例示である。固定の最適比率、審査条件、全ジャンル共通の販売法則ではない。

**制作提案**：各スタンプを「文言／使用場面／感情の強さ／原画／構図／文字配置／装飾／他と違う点」で一覧にする。用途が同じでも、親しさや感情の強さに差があるなら、その役割を記録する。

### 3.6 並び順と送受信時の見え方【公式事実】

公式の並び順の記事は、日常でよく使う返事や挨拶を上部へ配置することを勧めている。[S13]
公式マニュアルには、スタンプの送受信時の見え方を確認するシミュレータが案内されている。[S14]

S13には特定の位置が押されやすいという記述もあるが、2022年の記事である。現在の全端末・全画面で同じ順位になると断定しない。

**制作提案**：全枚数の一覧で似た構図の連続を確かめ、トークでの見え方も確認する。向きが意味を変える原画は送受信の両側で見る。公式の向きに関する助言を理由に、固有の模様や服装を含む原画を無条件に反転しない。

### 3.7 情報収集を具体的な制作判断に変える【公式事実・制作提案】

公式の制作サポート紹介では、対象者、キャラらしい表現、過去作との構図の重複を構成段階で確認し、完成後に文字・感情・装飾をチェックする流れが紹介されている。[S20]

かなぴさんの公式インタビューでは、日常のLINEや利用者のコメントから言葉をメモし、ストアでの色合いと余白のバランスを重視すると説明されている。[S21]
2026年8月公開のyopinkさんのインタビューでも、家族・友人とのLINEから発想し、見やすい文字と日常で使いやすい言葉を意識すると紹介されている。[S22]

公式編集部の作品紹介では、画面いっぱいのポーズ、独自の言い方、正面・横顔・後ろ姿、寄り引きなどを具体的に評価している。これは編集部の評であり、本リポジトリで画像の全点を直接比較した結果や売上ランキングではない。[S23]

**制作提案**：参考画像や記事を集めたら、「使用場面」「文言の温度」「キャラと文字の関係」「読みやすさの理由」「取り入れる要素」を [REFERENCE_CARD](../templates/REFERENCE_CARD.md) に記す。例として「左の二段文字と右の顔の大きさの関係を参考にする」のように、参照する範囲を明確にする。参考作品のキャラ・固有の図案をそのまま写す指示にはしない。

文字の細部では、Adobeの解説も、文字形状に応じて視覚的な間隔を整える方法を扱っている。[S24] 本制作では、完成サイズで字間・行間を確認し、縁取りを含む実際の字形で調整する考え方に応用する。特定の編集ソフトの導入を必須にはしない。

## 4. 自動制作に取り入れる判断

以下は上記の情報を制作へ落とした**提案**であり、実装済み機能の一覧ではない。

| 工程 | 自動処理で持たせる判断 | 確認する結果 |
|---|---|---|
| 原画の把握 | 顔、手、特徴、文字を置ける空間を整理 | 原画の魅力を隠していないか |
| 文言の整理 | 用途、口調、感情の強さを区別 | 送る場面が想像できるか |
| 構成案 | セット内の用途と構図の偏りを確認 | 役割が似たものばかりでないか |
| 文字組み | 改行や配置の複数候補を比較 | 読める文字サイズを確保できるか |
| 候補の選択 | 原画との適合、読みやすさ、変化を評価 | 色替えだけの差になっていないか |
| 単体の検品 | 文言、欠け、重なり、縁、背景を確認 | 指定どおりで、縮小しても意味が伝わるか |
| セットの検品 | 一覧で統一感と変化を同時に確認 | 同じキャラのまとまりがあるか |
| 書き出し | 規格、透過、容量、寸法を確認 | 提出用ファイルの条件を満たすか |

良い候補を選ぶための参考画像は、全体を真似る対象ではなく、文字の組み方や空間の使い方を分析する材料にする。参考作品のURL、観察した点、今回取り入れる理由を一緒に残す。

## 5. 販売後の改善に使える情報

### 5.1 確認できる統計【公式事実】

公式マニュアルには、アイテムごとの売上、販売数、送信数、スタンプ画像別の送信数が案内されている。利用者数や送信数等が少ない場合、項目が表示されないことがある。統計画面の売上は分配額の速報値で、確定金額とは区別される。[S15]

送信数の詳細画面では、地域や期間等での絞り込みとCSVダウンロードが案内されている。[S16]

### 5.2 統計から何を学ぶか【解釈・制作提案】

- 販売数はセットの購入、画像別送信数は購入後の使われ方を考える材料として分ける。
- 同じセット内で、どの文言・用途・感情の強さが使われたかを記録する。
- 送信数の違いを、文字サイズや構図だけの効果と断定しない。用途、並び順、季節、公開期間も関係し得る。
- 値が表示されない場合を、送信ゼロと扱わない。
- 次のセットで変える仮説を少数に絞り、変更前後の制作条件を記録する。
- 実績がまだない段階では、予想を「よく売れることが確認できた」と表現しない。

確認時の公式WEBヘルプでは、販売開始後の画像は変更できず、スタンプ・着せかえの表示情報は審査を経てアップデートできると案内している。[S17]
**制作提案**：画像そのものの差し替えと、登録する表示情報の更新を区別する。画像の改善案は次作品にも蓄積し、実際に販売中アイテムを更新する際は、その種別と更新対象の最新の条件を確認する。

## 6. フォントと素材の扱い

### 6.1 制作と配布で確認する範囲【公式事実】

LINEの審査ガイドラインは、第三者の権利侵害や使用素材の利用条件違反を対象としている。[S02]
書体の利用許諾は配布元ごとに異なる。例えば、もじワク研究は適用フォントのLINEスタンプへの画像使用を認める一方、無断の二次配布やフォントデータの改変・改変データ配布を禁止している。[S18]

Google Fontsの公式案内は、収録フォントがオープンソースのライセンスで公開され、商用・非商用のプロジェクトに利用できると説明している。[S19]

### 6.2 Museでの運用【制作提案】

1. 使用するフォント名、配布元URL、入手した版、ライセンスURL、確認日を記録する。
2. スタンプ画像としての商用利用と、フォントファイル自体の配布・組み込みを分けて確認する。
3. 許諾が確認できた書体を候補にし、原画に合う太さ・字形を比較する。
4. 指定フォントが読み込まれず、別の書体へ置き換わっていないか確認する。
5. フォントファイルをリポジトリへ含める必要が生じた場合は、その版の再配布条件を確認する。

無料配布という理由だけで、すべての商用利用や再配布が認められるとは扱わない。特定のフォントを採用する場合は、そのフォント自身の最新条件を確認する。

## 7. 審査と品質確認の接点

公式審査ガイドラインでは、視認性の悪さ、文字の誤り、単純なテキストだけの画像、販売画像と著しく異なるメイン・タブ画像などが挙げられている。[S02]

**制作提案**：文字を大きくすることだけを目的にせず、原画との組み合わせで意味が伝わるかを見る。申請前のチェックでは、誤字、濁点等の欠落、画像の切れ、原画の崩れ、透過の不具合、メイン・タブとの整合を確認する。

この資料は審査項目の全転載ではない。申請時は対象商品の制作・審査ガイドラインを再確認し、確認日を更新する。

## 9. 次に情報を追加するときの記録

- 規格の変更：商品種別、URL、変更を確認した日、既存の制作設定への影響。
- 参考作品：URL、観察日、具体的に参考になる点。売上が非公開なら成功理由を断定しない。
- そらさんの好み：採用例、修正例、どこを残したいか。抽象語だけでなく実物と理由を残す。
- 出力検品：完成画像、背景別・縮小プレビュー、問題箇所、修正結果。
- 販売後の実績：対象期間、地域、セット、画像別の数値、未表示項目、次作品への仮説。

この資料の提案は、原画と実際の制作結果を見て更新する。出典が説明する範囲、作品に対する解釈、試して確かめた結果を混ぜずに蓄積する。
