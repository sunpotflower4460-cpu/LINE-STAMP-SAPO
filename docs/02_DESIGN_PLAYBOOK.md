# デザイン実務ガイド — 原画と文字を一つのスタンプにする

更新・出典確認日：2026-11-11（日本時間）  
対象：既存キャラクター画像に文字を合成する、通常の静止画クリエイターズスタンプ。

この文書は制作判断のための設計資料であり、Museに記載機能が実装済みであることを示すものではない。実際に利用できる文字組み・画像合成・プレビュー機能は制作時に確認する。公式規格と出典の詳細は [調査・出典](01_RESEARCH_AND_SOURCES.md)、工程は [制作手順](03_PRODUCTION_WORKFLOW.md)、採否は [品質確認](04_QUALITY_CHECKLIST.md) を参照する。

文中のレイアウト、文言、候補数、配分、文字の大小などは、明記した公式要件を除き**制作上の提案例**。そらさんの指定文言・原画・採用済みデザインを優先する。

## 1. 最初に固定すること、毎回選び直すこと

自動制作でも、キャラクターの同一性、文言の意味、読みやすさを一緒に守る。変化は原画に合う配置や文字の表情から作る。

| 区分 | 基本的に固定するもの | 選び直してよいもの・条件 |
|---|---|---|
| キャラクター | 顔、体型、線の質、配色、衣装、固有の特徴 | 原画全体の等比拡縮と位置。表情・ポーズ生成、反転、描画部分のトリミングは案件で認められた範囲による |
| 文言 | 指定された文字、句読点、口調 | 文言提案を任されている場合の候補。改行も意味の区切りを守る |
| 文字の家族感 | 採用フォントの系統、縁の考え方、基本の濃さ | 配置、行数、強調語、字間・行間、控えめな角度 |
| セットの世界観 | キャラらしさ、対象者、日常語／敬語などの方針 | 会話での役割、感情の温度、文字とキャラのどちらを目立たせるか |
| 装飾 | 採用済みの線・形・色の雰囲気 | 意味がある場合の追加。装飾なしも候補にする |

元画像を再生成しなくても、文字位置、行数、強弱、文字と身振りの距離で変化は作れる。原画が一枚だけの場合、その原画で成立する変化を使い、ポーズ違いがすでにあるかのように扱わない。

## 2. 原画を見る順序

### 2.1 透明な画像枠ではなく、絵がある範囲を読む

1. 入力画像全体の幅・高さと、実際に絵が描かれている範囲を分けて把握する。
2. 顔、目口、手先、耳・髪・しっぽ、衣装の目印など、意味や個性を担う場所を確認する。
3. キャラが向いている方向、手や体の動き、上下左右の空き方を見る。
4. 文字が入る候補領域を複数挙げる。透明な場所があっても、顔の目前や手の動線なら慎重に扱う。
5. 原画と文字を合成したあと、両者を合わせた実描画範囲と見た目の重心を再確認する。

例えば、横幅の大きなPNGの中央に小さなキャラがある場合、PNG枠を基準に配置するとキャラと文字が離れやすい。描画部分を基準に並べる。位置計算のための範囲取得と、原画の内容を切り落とす処理は別物である。

アルファ値から取る範囲には、白い縁、半透明の影、細い髪なども含める。薄い部分を一律に不要と判定しない。孤立した点があれば、ゴミなのか意図した描写なのかを画像で確認する。

### 2.2 顔と手は「空いて見えても使わない」候補になりうる

- 目口は感情を伝える中心なので、文字や縁で隠さない。
- 手を振る、お辞儀する、何かを持つなどの意味を、文字の重なりで読み取りにくくしない。
- 耳・髪・しっぽ等と文字がちょうど接する配置は避ける。離れているのか重なっているのかが曖昧になる。
- 既存画像に小物がある場合、その小物も用途を伝える要素として扱う。文字を置くために勝手に消さない。
- 保護する領域は原画ごとに変える。「顔の上は必ず空ける」などの一律の大きな空白に置き換えない。

## 3. 二種類の余白を混同しない

| 余白 | 何と何の間か | 判断方法 |
|---|---|---|
| 外周の余白 | 書き出し画像の端と、絵・文字・縁などを合わせたコンテンツの外端 | 通常の静止画の公式ガイドは約10px。外側の安全余白として確保する |
| 内部の余白 | キャラと文字、文字同士、顔と吹き出し等の間 | 一体感と読みやすさで調整する。公式の約10pxをそのまま適用しない |

公式の通常静止画ページには、画像外枠とコンテンツの間に10pxぐらいの余白が必要と記載されている。別種類のスタンプや別資料にある余白処理を混ぜない。出典：[静止画制作ガイドライン](https://creator.line.me/ja/guideline/sticker/)（確認：2026-11-11）。

内部の隙間が大きいと、文字とキャラが別々の素材に見える。逆に詰めすぎると、縁がくっつき、手先や文字が潰れる。枠の座標だけでなく、輪郭同士の最も近い箇所と、全体の見え方を確認する。

余白が余って見えたときは、次の順に見直す。

1. 元PNGの透明部分を含めたまま位置を決めていないか。
2. キャラと文字の間だけに大きな隙間がないか。
3. 文言の改行や配置を変えると大きく置けないか。
4. 等比の範囲で、キャラ・文字の大きさを調整できないか。
5. 外周の約10pxまで削ろうとしていないか。

## 4. 文字組みの基礎

### 4.1 小さく押し込む前に配置を変える

公式は、文字数を抑えて見やすい大きさにすること、背景に埋もれないよう文字の縁を活用することを勧めている。出典：[効果的な文字の入れ方](https://note.com/line_cm/n/nf78791e5be9f)（確認：2026-11-11）。

- 文言提案を任されている場合は、用途が伝わる短い言い方を先に検討する。
- 指定文言の場合は勝手に短縮せず、意味のまとまりで改行し、別レイアウトと比較する。
- 大きさを揃える対象は、フォントの設定値よりも最終画像での見え方。文字数や書体が変われば同じ設定値でも印象は変わる。
- 文字を縦横別々に引き伸ばして収めない。窮屈なら配置や行数から修正する。
- 全文を同じ大きさにする案を基準にし、強調語がある場合だけ大小差の案を追加する。

### 4.2 字間と行間

| 確認箇所 | 見ること | 修正する方向 |
|---|---|---|
| 字間 | 文字の縁同士が合体していないか、単語がばらばらに見えないか | 実際の描画幅に合わせる。全字を一律に広げる前に接触箇所を確認 |
| 行間 | 上の行の下端と下の行の上端が潰れていないか | フォント枠ではなく縁を含む形で調整。離しすぎて別文に見せない |
| 改行 | 語や意味の途中で切れていないか | 「ありがとう／ございます」等、まとまりを保てる場所を候補にする |
| 濁点・半濁点 | 本体や隣の字、縁に埋もれていないか | 必要な隙間を確保し、書き出し後の縮小画像でも見る |
| 句読点・長音 | 行頭に孤立していないか、縦組みで向きが崩れていないか | 対応した文字組みを使う。対応不明なら横組みの候補を優先 |
| フォントの欠落 | 特定の字だけ別書体・空白・四角になっていないか | 実際に使う全文で確認し、対応する書体に揃える |

ここでの改行例は提案用であり、ユーザーが改行位置まで指定している場合はその指定を使う。縦書きや弧状配置を扱えるかは実行環境で確認する。

### 4.3 背景から分離し、絵となじませる

文字の縁は、読めることと絵柄に合うことの両方で決める。縁を太くすれば常に良くなるわけではなく、小さい字の内側が埋まる場合は調整する。

基本の書体・輪郭・色の関係を一度決め、その範囲で配置を変える。開始案としては「基本の書体一系統＋必要な強調用」程度でも比較できるが、数は規則ではない。

淡い原画ならまず文字や背景との境界を整える。キャラを勝手に濃く塗り直して解決しない。公式も、淡いタッチの輪郭や、顔色と目口の見分けやすさに注意を促している。出典：[見やすい色合い](https://note.com/line_cm/n/n924f2094c09d)（確認：2026-11-11）。

## 5. 8つのレイアウトを選ぶ条件

8種類を全セットに必ず入れる必要はない。原画と文言に合う候補を選ぶための引き出しである。以下の文言はすべて仮の例。

### A. 横一列

- **選ぶ条件**：短い文言を一読で伝えたい。上下どちらかに横方向の空きがある。
- **向く原画**：正面・上半身・座り姿など、文字と並べてもシルエットが保てるもの。
- **文言例**：「了解です」「おはよう」「ありがとう」。
- **配置**：上または下を比較し、キャラの視線・手の動きとつながる方を選ぶ。
- **避ける失敗**：長い文言を横一列に押し込む、透明PNGの枠に合わせて文字だけ遠ざける。
- **調整**：字を縮める前に二段案へ。上の手や耳とぶつかるなら下配置、足元が重要なら上配置を試す。

### B. 二段

- **選ぶ条件**：丁寧な文言等を読みやすい大きさで収めたい。意味の自然な切れ目がある。
- **向く原画**：左右どちらかにまとまった空きがあるもの、下方に重心のあるもの。
- **文言例**：「ありがとう／ございます」「よろしく／お願いします」。
- **配置**：文字のまとまりを一つの塊として扱い、キャラの横または上に置く。
- **避ける失敗**：一文字だけ次の行に送る、二行の間に大きな空間を作る、文字塊が顔を押しのける。
- **調整**：改行箇所、左右寄せ、文字塊の幅を比較する。上下二段にしただけで文字を大きくし忘れない。

### C. 縦書き

- **選ぶ条件**：日本語の短文で、細長い空きがある。縦方向の読み順が自然に成立する。
- **向く原画**：立ち姿、片側に寄った姿など、体の横に縦長の空間があるもの。
- **文言例**：「おつかれさま」「しょんぼり」。
- **配置**：原画の空いている側に一本の文字列を置き、顔・手先の近くを詰めすぎない。
- **避ける失敗**：横組みを90度回しただけ、長音や括弧の向きが不自然、長文で縦に伸びすぎる。
- **調整**：縦組み対応を確認し、読みにくければ横・二段へ。反転して空きを作ることは標準処理に含めない。

### D. 弧状

- **選ぶ条件**：短い言葉にやわらかさ・弾みを添えたい。頭上等に曲線を置ける空きがある。
- **向く原画**：輪郭が丸く、頭上の耳・髪・手と干渉しにくいもの。
- **文言例**：「ありがとう」「やったー」。
- **配置**：緩やかな弧から試し、文字の中央とキャラの重心を関係づける。
- **避ける失敗**：強く曲げすぎる、端の文字が寝る、文字の縁が耳や髪につながる。
- **調整**：まず曲がりを弱め、弧の幅と位置を整える。弧のためだけに原画を小さくしすぎない。

### E. 吹き出し

- **選ぶ条件**：キャラが話している感じを明確にしたい。背景から文字を分離する面があると読みやすい。
- **向く原画**：顔や口の向きがわかり、横または斜め上に空きがあるもの。
- **文言例**：「大丈夫だよ」「あとでね」。
- **配置**：吹き出しの向きと話者の位置を合わせる。文字を先に読みやすく組み、それを包む形を検討する。
- **避ける失敗**：吹き出しだけ巨大、しっぽが顔に刺さる、装飾枠のために文字が小さくなる。
- **調整**：吹き出し内の空きを見直し、しっぽを短くする。文字の縁だけで成立する案とも比較する。

### F. 文字の強弱

- **選ぶ条件**：一つの語に意味の中心がある。強調で口調が変わりすぎない。
- **向く原画**：感情が明確で、強調語を置く場所と表情を見せる場所が両立するもの。
- **文言例**：「本当にありがとう」「おつかれさまです」。
- **配置**：「ありがとう」「おつかれさま」等を主役にし、補助部分にも読める大きさを残す。
- **避ける失敗**：全部を強調する、助詞だけ極小、謝罪や気づかいが命令口調に見える。
- **調整**：大小差を弱める、色の強調を減らす。全文同サイズの案と見比べ、意味が伝わる方を選ぶ。

### G. 控えめな傾き

- **選ぶ条件**：原画の身振りに動きがあり、その方向を文字でも少し支えたい。
- **向く原画**：手を上げる、体を傾けるなど、すでに動きのある原画。
- **文言例**：「やったー」「まかせて」。
- **配置**：まず文字全体を一つの塊としてわずかに傾ける。角度に固定の正解はない。
- **避ける失敗**：一文字ずつランダムに傾ける、文字の端が外周へ飛び出す、静かな文言にも同じ勢いを付ける。
- **調整**：傾きを弱め、最後に回転後の外形で余白を測り直す。水平案より読みやすさが落ちるなら水平を採る。

### H. 文字を主役にする

- **選ぶ条件**：了承や短い返事など、文言を瞬時に見つけたい用途がある。
- **向く原画**：少し小さく配置しても顔と固有の特徴がわかり、文字に寄り添う位置を作れるもの。
- **文言例**：「OK」「了解」「ありがとう」。
- **配置**：文字のそばにキャラを置き、絵が言葉に反応しているような関係を作る。
- **避ける失敗**：キャラが認識できないほど小さい、文字だけの画像に見える、余白を飾りで埋める。
- **調整**：キャラの見える大きさを先に確保し、文字との比率を決める。文字の主張が強すぎれば横一列案に戻す。

## 6. 文字とキャラクターの一体感

### 6.1 空いている場所に入れるだけで終わらせない

手の動き、顔の向き、体の重心と文字を結びつける。例えば手を上げた原画なら、その手の近くに短い挨拶を置く候補が考えられる。ただし手先に文字を接触させる必要はない。

一体感は距離だけでも作れる。吹き出し、ハート、星、集中線を追加する前に、文字とキャラの位置だけで成立する案を作る。

### 6.2 感情の温度を合わせる

| 意図 | 試す方向 | 避けたいズレ |
|---|---|---|
| 元気な挨拶 | 大きめの短文、動きに沿う配置 | 全要素を派手にして顔が埋もれる |
| 丁寧な感謝 | 安定した文字塊、自然な改行 | 文字を細く小さくして丁寧さを表現する |
| 気づかい | 読める大きさを保ち、角度や装飾を抑える | 命令や大声に見える強調 |
| 小さな喜び | 緩やかな弧や軽い強弱を候補にする | 原画の控えめな笑顔に爆発的な演出を加える |
| 疲れ・しょんぼり | 原画の静けさを活かす | 文言が読めないほど薄く小さくする |

そらさんが特定のずれやユーモアを意図している場合は、その意図を優先する。上表は無意識な不一致を見つけるための例である。

### 6.3 装飾にも役割を持たせる

- 装飾を消した候補と比較し、感情が伝わりやすくなった場合に残す。
- 星やハートを増やすことを「高品質化」の代わりにしない。
- 顔、文言、装飾のどこを先に見てほしいか決める。全部を同じ強さにしない。
- キャラの線に対して装飾だけ極端に細い、硬い、鮮やかすぎる状態を確認する。
- 装飾を加えた後は、合成画像全体の外形が広がっていないか確認する。

## 7. セット全体で統一と変化を両立する

各画像が良くても、一覧で見たときに全て「上に文字・下にキャラ」だと変化が見えにくい。反対に、書体・色・縁・配置が全部違うと、同じキャラのシリーズとしてまとまりにくい。

公式編集部は、全身と表情の変化、正面・横顔・後ろ姿、寄り引きなどを作品の長所として挙げている。出典：[編集部による作品紹介](https://note.com/line_cm/n/n820d1548e4be)（確認：2026-11-11）。本資料では、提供された原画群の中でこうした違いを活かす。新しい向きやポーズの生成を自動的に追加する根拠にはしない。

| 一覧で見る軸 | 揃えること | 変化を作ること |
|---|---|---|
| 会話での用途 | セットの対象者と口調 | 挨拶、返事、感謝、気づかい、連絡、気分 |
| 文字組み | 書体・輪郭の家族感 | 横・二段・縦など、原画に合う配置 |
| 大小 | 小さい表示でも読める水準 | 文字主役、キャラ主役、両者が同程度のもの |
| 色 | 共通する色の考え方 | 必要な箇所だけアクセントを使う |
| 密度 | 潰れず、離れすぎないこと | 静かな案、少し弾む案、強い反応の案 |

同じ用途・似た原画が続くときに別の型を試す。全ての型を均等配分することより、使いやすさと全体の違いが見えることを優先する。例えば初回は三つの型を比較する方法もあるが、候補数も配分も提案であり必須条件ではない。

## 8. 概念サンプル6枚

以下は実画像の分析や完成案ではない。該当する原画が提供された場合の組み方を説明する仮例。描かれていない表情・ポーズ・小物の追加は前提にしない。

### 例1：手を振る原画 ×「おはよう」

- 第一候補：横一列。手を振る意味が見える側を残し、上または下に文字を寄せる。
- 比較候補：原画の動きに合えば、文字全体に控えめな傾きを付ける。
- 採否：顔と手が見えるか、文字が離れていないか、挨拶の明るさが原画と合うか。

### 例2：お辞儀の原画 ×「ありがとうございます」

- 第一候補：「ありがとう／ございます」の二段。頭の上か横の空きを候補にする。
- 比較候補：同じ文言を横一列にして、縮小時にどちらが読みやすいか比較する。
- 採否：お辞儀の姿勢が読めるか。丁寧さを出そうとして字を小さくしすぎていないか。

### 例3：片側に寄った立ち姿 ×「おつかれさま」

- 第一候補：原画の空いている側に縦書き。目口・手先に文字がかからない位置を探す。
- 比較候補：上または下の横一列。縦組みが細長くなりすぎるならこちらを採る。
- 採否：自然に読めるか。空間を作るために原画を反転・変形していないか。

### 例4：喜ぶ原画 ×「やったー」

- 第一候補：緩やかな弧。原画の表情と文字の明るさを合わせる。
- 比較候補：水平の横一列、または控えめな傾き。まず装飾なしで比較する。
- 採否：弧の端の文字、長音、耳や髪との距離が読みやすさを妨げていないか。

### 例5：穏やかな表情の原画 ×「大丈夫だよ」

- 第一候補：小さくまとめた吹き出しに、十分読める文字を置く。
- 比較候補：吹き出しを外して縁付きの文字だけを置く。
- 採否：気づかいとして伝わるか。大声や指図のような強調になっていないか。

### 例6：顔と特徴が明確な原画 ×「了解です」

- 第一候補：文字主役。キャラが識別できる大きさを保ち、文字に近づける。
- 比較候補：「了解」を少し強くする案と、全文同じ大きさの横一列案。
- 採否：「です」が読めるか。文字とキャラが別の場所に浮いていないか。

## 9. よくある失敗と直し方

| NG | 起きていること | 修正すること |
|---|---|---|
| キャラと文字の間に大きな穴がある | 透明PNG枠を基準に位置決めしている可能性 | 実描画範囲を見直し、内部の距離を詰めて再配置 |
| 十分な空きがあるのに文字が小さい | 固定サイズや固定の文字箱で処理している | 文字箱を見直し、意味のまとまりを保って拡大 |
| 長文の一文字だけが次の行にある | 収まりだけで自動改行した | 意味の切れ目で二段を組み直す。指定文言は保持 |
| 顔や手が文字で隠れる | 顔・身振りを保護していない | 別の配置型を選ぶ。元画像を描き直す前に配置を直す |
| 耳や髪と文字の縁がくっつく | 枠の隙間と輪郭の隙間が違う | 最も近い輪郭を確認して離す |
| 全て同じ位置の文字になる | 一枚ごとの形を読まず固定配置している | 原画の空き方ごとに候補を選び、一覧で再比較 |
| 毎回違う書体と色になる | 変化を文字の見た目だけで作っている | 基本の書体・輪郭を揃え、配置や用途に変化を移す |
| 縁を太くしたら文字が潰れた | 縁が内側や隣の字を埋めている | 縁・字間・文字サイズを調整し、縮小版で確認 |
| 暗い背景で文字が消える | 背景との分離が足りない | 文字の縁や面を調整。原画の配色変更で代用しない |
| 原画の表情と文言が合わない | 文言や強調の温度がずれた | 文言提案の範囲なら候補変更。指定文言なら別原画・配置を検討 |
| かわいさを足したら散らかった | 星・ハート等が主役より強い | 装飾なしに戻して比較し、必要なものだけ採る |
| 文字を大きくしたらキャラが小さすぎる | 文字の収まりだけを最適化した | 文字・キャラの両方を認識できる配置へ変更 |

## 10. 一枚ごとの判断を短く残す

制作時は「いい感じにした」ではなく、次の情報を残すと修正を再現しやすい。

- 原画ID、正確な文言、使用場面、想定する口調。
- 顔・手・特徴など、守った場所。
- 採用した配置と、比較した別案。
- 文字とキャラの距離・大小・装飾をどう判断したか。
- 読みにくかった点と、実際に直した箇所。
- 確認した背景と表示サイズ。見ていない条件は未確認と記す。

制作案の例：「原画A／了解です。横一列と文字主役を比較し、後者はキャラの目が小さくなるため横一列を採用。手先を避けて下に配置。星は外した方が表情が伝わった」。これは記録形式の説明であり、実制作や検証の報告ではない。
