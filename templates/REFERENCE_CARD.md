# 参考資料の記録 — REFERENCE_CARD

参考画像・記事を1件ずつ記録する。画像そのものを見た観察、商品説明、編集部の評価、自分の提案を区別する。対象者やキャラの雰囲気が近い例に加え、文字配置や余白など特定の技法が分かる例も使う。

## 記入テンプレート

| 項目 | 記入欄 |
|---|---|
| 参考ID | 未記入 |
| 作品名・記事名 | 未記入 |
| 作者・発信者 | 未記入 |
| 出典URL | 未記入 |
| 公開日／閲覧日 | 未確認／未記入 |
| 観察の種類 | 画像を直接確認／作者の説明／公式編集部の評価／文章のみ |
| 使う場面・相手 | 分かる範囲で記入 |
| 文言・口調・感情の強さ | 分かる範囲で記入 |
| キャラと文字の配置 | 顔と文字の位置、行数、大小関係など |
| 読みやすさを支える点 | 文字の太さ、字間、色、縁取り、背景との分離など |
| 余白・装飾の使い方 | 空けている場所、詰めている場所、装飾の役割 |
| 自分の作品に取り入れる点 | 何を、どの原画や文言で試すか |
| 参照の範囲 | 例：文字の配置だけ。キャラ・固有の口癖・独自の図案は参照範囲に含めない |
| 次に試す候補 | 比較できる具体的な案 |

## 架空の記入例

以下は記入方法を示す仮の例であり、実在作品の観察結果ではない。

- 観点：大きな文字と顔の両方が読み取れる配置。
- 想定配置：左に二段の文字、右にキャラ。顔と文字の高さが近い。
- 取り入れる点：自分の原画の実描画範囲を見て、文字との距離を調整する。
- 試す文言：「いつもありがとう」。二段案と横一段案を比較する。
- 判断：小さく表示したときに全文と表情が分かるか。明暗の背景で縁が保たれるか。
- 状態：未制作・未確認。

## 情報収集を制作に結びつける

1. 何を良くしたいか決める。例：長い文言、縦書き、静かな表現、余白の詰め方。
2. その観点が分かる参考を少数選ぶ。
3. 参考画像の特徴を、上の表の言葉で説明する。
4. 自分の原画に合わせた案を作り、参考で理解した効果が出ているか見る。
5. 採用した理由と、使えなかった理由を [REVIEW_LOG](REVIEW_LOG.md) に残す。

順位や販売実績を確認していない作品を「売れている証拠」として扱わない。数値を使う場合は出典、期間、対象、取得日を付ける。古い公式記事は制作の考え方として使い、現在の需要の数値と区別する。
